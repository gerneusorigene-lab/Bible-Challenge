# Sprint 3.1.1 — Topic Flow and Navigation

## Changes

- Selecting a story now starts a randomized queue containing every related question for that story.
- Related question records are grouped into player-facing stories (for example, both Noah records form one Noah's Ark story).
- Story cards display the number of playable questions in the selected story.
- Journey progress is calculated by completed stories rather than individual question records.
- Play Journey always shuffles the selected journey instead of starting from the first database record.
- The global sound control is hidden on the Story List screen so it cannot overlap or intercept the page Back button.
- Back returns to Choose Journey.

## Free tier

Free users only receive questions whose IDs are included in the free question allowance. Premium story groups include every related question.
